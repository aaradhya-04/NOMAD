# 🧭 NOMAD — Smart Relocation Companion Platform

> A web-based platform helping students and working professionals adapt to new cities through integrated city intelligence, accommodation listings, and community-driven interaction.

---

## 📌 Project Overview

**NOMAD** is a full-stack web application designed to make relocation less stressful and more informed. Users can explore cost of living, safety insights, cultural information, and accommodation listings — all in one place — while also connecting with local residents for real-world guidance and support.

## 🚀 Features

- **City Dashboard** — Explore cost of living, weather, transportation, and area-wise safety/affordability for any city
- **Accommodation Listings** — Browse user-posted listings with neighborhood context and community reviews
- **Human Interaction Module** — Connect with local residents for real guidance; send/respond to help requests
- **Community Posts** — Locals share experiences, tips, and recommendations
- **User Profiles** — Manage preferences, relocation goals, and destination city
- **Relocation Toolkit** — Checklists and planning resources to organize your move
- **Single-Page Application** — Fast, section-based navigation with no page reloads

---

## 🏗️ Architecture

The system follows a **MERN stack SPA** architecture:

- **Frontend (React.js)** communicates with the backend via RESTful APIs
- **Backend (Node.js + Express.js)** handles business logic, user requests, and data processing
- **Database (MongoDB)** stores user profiles, city data, accommodation listings, posts, and interactions
- **Authentication** is managed via JWT with bcrypt-encrypted passwords

Modules: User Management · City Data · Accommodation · Human Interaction · Community Posts · Reviews

## ⚖️ Advantages & Disadvantages

**Advantages**
- Centralized platform — no need to juggle multiple apps
- Community-driven content improves real-world accuracy
- Modular and scalable design
- Secure auth and data privacy

**Disadvantages**
- Depends on user-generated content (moderation needed)
- Limited data at launch for less-covered cities
- Real-time features increase system complexity
